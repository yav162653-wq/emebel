## 🎯 ASOSIY TALABLAR (NASA-style mindset)

NASA yondashuvi quyidagilarni talab qiladi:

1. **Modullarga bo‘lingan** (hech narsa chalkash emas)
2. **Markaziy boshqaruv** (state, auth, routing)
3. **Izolyatsiya** (bir modul boshqasini buzmaydi)
4. **Kengayuvchanlik** (100+ feature qo‘shsa ham sinmaydi)
5. **Predictable flow** (har doim qayerdan qayerga o‘tayotgani aniq)

## 🧠 `app/` – MARKAZIY BOSHQARUV (MISSION CONTROL)

```
app/
├── App.tsx
├── providers/
│   ├── AuthProvider.tsx
│   └── ThemeProvider.tsx
├── router/
│   ├── AppRouter.tsx
│   └── routes.ts
└── store/
    ├── auth.store.ts
    └── furniture.store.ts
```

### 🧩 Bu nima?

* **AuthProvider** – login/logout holati
* **store/** – in-memory global state (Redux/Zustand stilida)
* **router/** – kim qayerga kira oladi

👉 **NASA qoidası:**

> UI hech qachon biznes logikani bilmasligi kerak

## 🗺️ ROUTING (AUTH-GUARDED)


### Logic:

* Auth yo‘q → faqat `Landing`, `Login`
* Auth bor → `HeroSection`

```ts
if (!isAuthenticated) {
  return <PublicRoutes />
}
return <PrivateRoutes />
```

```
   ↓

   ↓
```
